# 너의 꽃길 — 올리는 방법

컴퓨터에 따로 설치할 프로그램은 없어요. **GitHub 계정(무료)** 하나만 있으면 돼요.
(화면 이름은 시간이 지나면 조금 달라질 수 있어요.)

## 1단계. 웹으로 올리기 (아이폰·갤럭시 모두 사용)

1. github.com 에서 계정을 만들고 로그인해요.
2. 오른쪽 위 **＋ → New repository** 를 눌러요.
   - 이름: `kkotgil` (아무 이름이나 괜찮아요)
   - **Public** 으로 두고 **Create repository** 를 눌러요.
3. 새 저장소 화면에서 **uploading an existing file** 을 눌러요.
4. 이 압축을 푼 폴더 **안의 파일과 폴더를 전부** 끌어다 놓아요.
   (`docs` 폴더, `assets` 폴더, `.github` 폴더, `package.json` 등)
   - 점으로 시작하는 `.github` 폴더가 안 보이면 2단계의 "대신 이렇게" 를 보세요.
5. 아래쪽 **Commit changes** 를 눌러요.
6. 저장소의 **Settings → Pages** 로 가서
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/docs** → **Save**
7. 1~2분 뒤 같은 화면에 주소가 나와요. 보통 `https://내아이디.github.io/kkotgil/` 예요.
8. 그 주소를 폰에서 열고 **홈 화면에 추가** 하세요.
   - 아이폰: 사파리 → 공유 버튼 → 홈 화면에 추가
   - 안드로이드: 크롬 ⋮ 메뉴 → 홈 화면에 추가

이 주소는 누구나 열 수 있어요. 로그인하지 않으면 기록은 각자 폰에만 저장돼요. (구글 계정에 저장하려면 5단계)

## 2단계. 안드로이드 앱 만들기 (약·접종 알림이 울려요)

1. 같은 저장소에서 **Actions** 탭을 눌러요. 안내 문구가 나오면 활성화(Enable)해요.
2. 왼쪽 **Android APK** → **Run workflow** → 초록 **Run workflow** 를 눌러요.
3. 10~20분 정도 기다려요. 초록 체크가 뜨면 성공이에요. (빨간 X가 뜨면 그 화면을 캡처해서 알려주세요.)
4. 다 만들어지면 다운로드 주소가 **저절로** 생겨요. 폰에서 `https://내아이디.github.io/저장소이름/install.html` 을 열고 **앱 내려받기** 를 눌러 설치해요. (자세한 건 7단계)
   - 예전 방법도 그대로 돼요. 완료된 작업을 열고 맨 아래 **Artifacts** 의 `kkotgil-apk` 를 내려받아 압축을 풀면 `app-debug.apk` 가 나와요. 이걸 폰으로 옮겨서 눌러 설치해요.
5. "출처를 알 수 없는 앱" 허용을 물으면 허용해요.
6. 앱을 열고 **알림 허용** 을 눌러요. 이제 약과 접종 일정을 저장할 때마다 알림이 자동으로 예약돼요.

### 대신 이렇게 (.github 폴더가 올라가지 않았을 때)
저장소에서 **Add file → Create new file** 을 누르고, 파일 이름 칸에
`.github/workflows/android.yml` 을 입력한 다음, 이 폴더의 같은 파일 내용을 붙여넣고 저장해요.

### 알람 소리 바꾸기
- 앱(또는 웹 주소)의 오른쪽 위 **설정 → 알람 소리** 에서 10가지 중 하나를 골라요. **듣기** 로 미리 들어볼 수 있어요.
- 고른 소리는 약·접종 알림이 울릴 때 나요. 고르면 알림이 새 소리로 다시 예약돼요.
- 소리 파일은 직접 만든 간단한 효과음이에요(`docs/sounds` 폴더). 다른 소리를 쓰고 싶으면 같은 이름의 .wav 파일로 바꿔 올리면 돼요.
- 소리가 안 나면: 휴대폰 설정 → 앱 → 너의 꽃길 → 알림 에서 "알람 소리: ○○" 항목의 소리가 켜져 있는지 확인해요.

## 3단계. 기존 기록 옮기기
웹 주소와 앱은 저장 공간이 각각 따로예요. 예전에 쓰던 기록은
- 옛 화면 ☰ **설정 → 백업 · 복원 → 백업 내용 만들기** 로 글을 복사하고,
- 새 앱의 **설정 → 백업 · 복원** 칸에 붙여넣고 **이 내용으로 복원** 을 눌러요.

## 4단계. 숫자 공유 코드 서버 만들기 (선택 · Cloudflare 무료)

설정의 **공유 코드**를 `1234 5678` 같은 **숫자 8자리**로 쓰려면, 코드를 잠깐 맡아 주는 작은 서버가 필요해요.
이 단계를 건너뛰어도 앱은 그대로 잘 돌아가요. 대신 공유 코드가 예전처럼 긴 글자 코드(`KG2:`로 시작)로 만들어져요.

### 이 서버가 하는 일 (개인정보)
- "코드 만들고 복사하기"를 눌렀을 때만, 그 아이의 정보(이름·나이·메모·동물등록번호, "기록도 함께"를 켰다면 기록까지)가 서버에 **24시간** 맡겨져요. 사진은 보내지 않아요.
- 받는 사람이 코드를 입력하면 **딱 한 번만** 내주고 바로 지워요. 아무도 안 가져가도 24시간 뒤에 지워져요.
- 코드는 무작위 8자리예요. 틀린 코드를 계속 넣으면 잠시 막혀요(한 기기당 10분에 10번).
- 서버를 만든 사람(내 Cloudflare 계정)은 맡겨져 있는 동안의 내용을 볼 수 있어요.
- 서버 주소는 비밀번호가 아니라서 GitHub에 올라가도 괜찮아요.

### 만드는 순서 (처음이면 20분쯤)
화면 이름은 시간이 지나면 조금 달라질 수 있어요. 안 보이면 그 화면을 캡처해서 알려주세요.

1. **dash.cloudflare.com/sign-up** 에서 계정을 직접 만들어요. 무료 요금제면 충분해요. (카드 등록을 요구하면 멈추고 알려주세요.)
2. 왼쪽 메뉴에서 **D1 SQL database** (Storage & databases 안에 있어요) → **Create Database** → 이름 `kkotgil-share` → **Create**.
3. 왼쪽 **Workers & Pages** → **Create application** → **Start with Hello World!** → **Get started** → 이름 `kkotgil-share` → **Deploy**.
   - 처음이면 `workers.dev` 주소에 쓸 내 이름을 정하라고 해요. 영문 소문자·숫자로 아무거나 정하세요.
4. 배포가 끝난 화면의 **Edit code** (`</>` 모양)를 눌러요. 가운데 `worker.js` 안의 글을 **전부 지우고**, 이 폴더의 `server/worker.js` 내용을 **전부 붙여넣어요**.
   오른쪽 위의 **Deploy** 를 눌러요. (버튼이 **Save** 라면 저장한 뒤 **Deployments → Deploy version → Deploy**)
5. 이 Worker(`kkotgil-share`) 화면 가운데 그림 **오른쪽의 Bindings 상자**에서 **Add a binding** 을 눌러요. (화면에 따라 위쪽 **Bindings** 탭이나 **Settings** 안에 있기도 해요. 상자가 잘리면 Ctrl 과 마이너스(-)로 화면을 줄여 보세요.) → **D1 database**
   - **Variable name** 칸에 `DB` (대문자 두 글자, 정확히!)
   - 목록에서 2번에서 만든 `kkotgil-share` 데이터베이스를 고르고 **Add binding**
   - **Deploy** 버튼이 보이면 한 번 더 눌러요.
6. Worker 화면에 보이는 주소 (`https://kkotgil-share.○○○.workers.dev`)를 복사해서 새 탭에 열어 보세요.
   **"너의 꽃길 공유 서버가 켜져 있어요. 데이터베이스 연결: 잘 됨 ✅"** 이 보이면 성공이에요.
   - **"안 됨 ❌"** 이면 5번의 변수 이름 `DB` 를 다시 확인해요.
   - 만든 직후에 오류가 나면 1분쯤 뒤에 다시 열어 보세요.
7. GitHub 저장소의 `docs` 폴더에서 **config.js** 를 열고 연필(✏️) 버튼을 눌러요.
   `window.KG_SERVER='';` 를 `window.KG_SERVER='복사한 주소';` 로 바꾸고 **Commit changes**. (주소 끝에 `/` 는 붙이지 마세요.)
   - 이 압축에 든 새 `docs/index.html` 도 같은 방법으로 올려서 바꿔 주세요.
   - (이 압축의 `docs/config.js` 에는 이미 만든 서버 주소가 들어 있어요. `docs/index.html` 과 `docs/config.js` 두 파일만 `docs` 폴더에 올리면 돼요.)
8. 1~10분 뒤 웹 주소를 새로고침하면 공유 코드가 숫자로 만들어져요.
   안드로이드 앱은 2단계처럼 **Run workflow** 로 새 APK를 만들어 설치해요.
   (설치하기 전에 **설정 → 백업 · 복원** 으로 기록을 꼭 복사해 두세요.)

### 문제가 생기면
- 주소를 열었는데 **"안 됨 ❌"** → Bindings 의 변수 이름이 `DB` 인지, 데이터베이스를 골랐는지 확인.
- 앱에서 **"서버에 연결하지 못해 글자 코드로 만들었어요"** → `docs/config.js` 의 주소(따옴표, `https://`, 끝에 `/` 없음)를 확인하고, 웹은 10분쯤 기다렸다가 새로고침.
- **"없는 코드이거나 이미 썼거나 24시간이 지났어요"** → 코드는 한 번만, 24시간 안에만 써져요. 보낸 사람에게 새로 만들어 달라고 해요.
- **"틀린 횟수가 많아요"** → 10분 뒤에 다시 해요.
- 무료 한도(하루 요청 수 등)는 개인이 쓰기엔 충분하지만, Cloudflare 정책은 바뀔 수 있어요.

## 5단계. 구글 계정으로 로그인하기 (선택 · 무료)

앱을 켜면 첫 화면에 로고와 **Google 계정으로 시작하기** 버튼이 떠요. 로그인하면 기록이 내 계정에 저장되고,
다른 폰에서 같은 구글 계정으로 로그인하면 그동안 저장해 둔 기록이 그대로 나와요.

- **4단계(서버)를 먼저 만들어 두어야 해요.** 같은 서버가 로그인과 저장도 맡아요.
- 이 단계를 건너뛰어도 돼요. 로그인 화면의 **나중에 하기** 를 누르면 예전처럼 이 폰에만 저장하며 써요.
- 구글 설정을 아직 안 했는데 로그인 버튼을 누르면 "서버에 구글 설정이 아직 안 돼 있어요" 라고 나와요.

### 로그인하면 무엇이 저장되나요 (개인정보)
- 구글에서 받는 것은 **이름 · 이메일 주소 · 계정 고유번호** 뿐이에요. 비밀번호는 구글 화면에서만 입력하고, 앱과 서버는 볼 수 없어요.
- 서버에는 아이 정보(사진 포함) · 일기 · 몸무게 · 접종 · 약 · 복용 체크가 통째로 저장돼요. 알람 소리와 화면 색 설정은 폰마다 따로예요.
- **서버를 만든 사람(내 Cloudflare 계정)은 저장된 내용을 볼 수 있어요.** 다른 사람이 로그인해서 쓰게 한다면 미리 알려 주세요.
- 한 계정이 맡길 수 있는 크기는 1.5MB 까지예요. 사진이 아주 많으면 줄이거나 지워야 할 수 있어요.
- 로그인은 180일 동안 유지되고, 쓸 때마다 늘어나요. **로그아웃** 은 그 폰의 로그인만 풀어요.
- 설정 → **내 계정** → **계정 삭제** 를 누르면 서버에 있는 내 기록과 로그인 정보가 모두 지워져요. 폰 안의 기록은 그대로 남아요.
- 여러 폰에서 거의 동시에 고치면 두 쪽을 합쳐요. 이때 예전에 지운 기록이 다시 나타날 수 있어요.

### 새 파일 올리기
이번에 바뀐 파일은 `docs/index.html`, `docs/native.js`, `package.json`, `.github/workflows/android.yml`, `server/worker.js`, `README.md` 예요.
`server/worker.js` 는 GitHub 에 올리는 용도가 아니라 Cloudflare 에 붙여넣는 용도예요(아래 1번).
`.github/workflows/android.yml` 은 저장소에서 그 파일을 열고 연필(✏️) 버튼으로 내용을 전부 새 내용으로 바꾼 뒤 **Commit changes** 를 눌러요.
(또는 `https://github.com/내아이디/저장소이름/upload/main/.github/workflows` 를 열어 `android.yml` 을 끌어다 놓고 **Commit changes**.)

### 만드는 순서 (처음이면 30분쯤)
화면 이름은 시간이 지나면 조금 달라질 수 있어요. 영어 이름은 구글 화면에 보이는 그대로 적었어요.

1. **새 서버 코드부터 올려요.** Cloudflare → Workers & Pages → `kkotgil-share` → **Edit code** 에서 `worker.js` 안의 글을 전부 지우고,
   이 폴더의 새 `server/worker.js` 내용을 전부 붙여넣어 **Deploy** 해요. (4단계의 4번과 같아요.)
   서버 주소를 새 탭에 열었을 때 **"구글 로그인: 아직 켜지 않았어요 ⚠️"** 과 맨 아래 **리디렉션 URI 에 넣을 주소** 가 보이면 새 서버가 켜진 거예요.
   그 주소(`https://….workers.dev/auth/callback`)를 복사해 두세요. 4번에서 써요.
2. **console.cloud.google.com** 에 구글 계정으로 로그인해요. 위쪽의 프로젝트 선택 상자 → **New project** → 이름 `kkotgil` → **Create**.
   만든 뒤 위쪽 상자에 그 프로젝트 이름이 보이는지 확인해요.
3. 위쪽 검색창에 `Google Auth platform` 을 입력해 열고 **Get started** 를 눌러요.
   - App name: `너의 꽃길`, User support email: 내 메일 → **Next**
   - Audience: **External** → **Next**
   - Contact Information: 내 메일 → **Next**
   - 마지막 화면에서 사용자 데이터 정책 동의 칸에 체크하고 **Continue**, **Create** 를 눌러요.
   그다음 왼쪽 메뉴 **Audience** 에서 Publishing status 가 **Testing** 인지 확인하고, **Test users** 에서 **Add users** → 로그인에 쓸 구글 메일을 모두 넣고 **Save**.
   - **Publish app 은 누르지 마세요.** 이름·이메일 같은 기본 권한만 쓰면 테스트 상태로 두어도 돼요.
   - 구글 문서에는 기본 권한만 쓰면 테스트 사용자 목록에 없어도 된다고 나오지만, 막힐 때를 대비해 내 메일은 넣어 두면 안전해요.
4. 왼쪽 메뉴 **Clients** → **Create client** → Application type 은 **Web application** → Name `kkotgil`.
   - **Authorized redirect URIs** 의 **Add URI** 를 눌러 1번에서 복사한 주소(`https://….workers.dev/auth/callback`)를 **한 글자도 틀리지 않게** 붙여넣어요.
   - **Create** 를 눌러요.
5. 뜨는 창의 **Client ID** 와 **Client secret** 을 복사해서 메모장에 붙여 두어요.
   - **Client secret 은 만든 직후에만 전체가 보여요.** 창을 닫기 전에 꼭 복사하세요. (잃어버리면 새로 만들면 돼요.)
   - 이 두 값은 비밀번호예요. GitHub 에 올리거나 남에게 보내지 마세요.
6. **Cloudflare** → Workers & Pages → `kkotgil-share` → **Settings** → **Variables and Secrets** → **Add**
   - Type **Text**, Variable name `GOOGLE_CLIENT_ID`, Value 는 5번의 Client ID → 저장
   - 한 번 더 **Add**: Type **Secret**, Variable name `GOOGLE_CLIENT_SECRET`, Value 는 5번의 Client secret → 저장
   - 아래의 **Deploy** 를 눌러요.
7. 서버 주소를 새 탭에 다시 열어요. **"구글 로그인: 켜져 있어요 ✅"** 이 보이면 성공이에요. (안 바뀌면 1분쯤 뒤 새로고침.)
8. GitHub 에 위의 새 파일들을 올리고(**`.github/workflows/android.yml` 은 맨 마지막에**), 2단계처럼 새 APK 를 만들어 폰에 설치해요.
   - 올릴 때 `android.yml` 을 올리면 APK 만들기가 저절로 시작돼요. 그래서 다른 파일을 먼저 올려야 해요.
   - **새 APK는 옛 앱 위에 덮어 설치되지 않아요.** (7단계의 같은 도장을 쓴 뒤로 만든 앱끼리는 덮어 설치돼요.) 옛 앱을 지우고 새로 설치해야 해서 기록이 사라져요. 지우기 전에 **설정 → 백업 · 복원 → 백업 내용 만들기** 로 기록을 꼭 복사해 두세요.
   - 새 앱에서 로그인한 뒤, 복사해 둔 백업을 복원하면 기록이 계정에도 올라가요.
   - 설정의 앱 정보에 **앱 버전: 2026.10.23 (계정 로그인)** 이 보이면 새 앱이에요.

### 선택: 허락한 사람만 쓰게 하기
기본은 "구글 계정이 있는 누구나" 로그인할 수 있어요(내 서버 저장 공간을 쓰게 돼요).
내 가족·봉사자만 쓰게 하려면 위 6번처럼 **Add** 로 Type **Text**, Variable name `ALLOW_EMAILS`,
Value 에 `aaa@gmail.com,bbb@gmail.com` 처럼 쉼표로 메일을 적고 **Deploy** 해요. 목록에 없는 계정은 "이 앱을 쓸 수 있는 목록에 없어요" 가 나와요.

### 폰에서 로그인하는 모습
1. 앱 첫 화면의 **Google 계정으로 시작하기** 를 누르면 크롬 창이 열려요.
2. 구글에서 계정을 고르고 허용하면 "로그인이 끝났어요" 화면이 나와요. 앱으로 자동으로 돌아오지 않으면 그 화면의 **앱으로 돌아가기** 버튼을 눌러요.
3. 이미 기록이 있는 폰이 이미 기록이 있는 계정에 처음 로그인하면, **합치기 / 계정 기록으로 바꾸기 / 취소** 중에서 골라요.

### 문제가 생기면
- 구글 화면에 **redirect_uri_mismatch** → 4번에 넣은 주소가 서버 주소 + `/auth/callback` 과 한 글자도 다르지 않은지 확인해요(`https://`, 끝에 `/` 없음). 고친 뒤 반영에 5분에서 몇 시간까지 걸릴 수 있어요.
- 구글 화면에 **액세스 차단됨 / Access blocked** → 3번의 **Test users** 에 그 메일이 있는지 확인해요.
- 구글 화면에 **Google hasn't verified this app (확인되지 않은 앱)** 경고 → 내가 만든 앱이라 나오는 경고예요. **Advanced (고급)** → **Go to … (unsafe)** 를 눌러 계속해요.
- 서버 주소에 **"아직 켜지 않았어요 ⚠️"** → 6번의 변수 이름 철자(`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`)를 확인하고 **Deploy** 를 눌렀는지 봐요.
- 앱에 **"서버가 예전 버전이에요"** → 1번처럼 새 `worker.js` 를 붙여넣고 **Deploy**.
- 앱에 **"서버에 구글 설정이 아직 안 돼 있어요"** → 6~7번을 다시 확인해요.
- 앱이 계속 로그인 화면에 머물러요 → 구글 창에서 **앱으로 돌아가기** 를 눌러요. 그래도 안 되면 새 APK(8번)를 설치했는지 확인해요.
- 다른 폰에서 기록이 안 보여요 → 인터넷을 확인하고 설정 → **내 계정** → **지금 맞추기** 를 눌러요. 두 폰 모두 같은 구글 계정으로 로그인했는지도 확인해요.
- 로그인이 막혀서 급하게 앱을 써야 해요 → 로그인 화면의 **나중에 하기** 로 들어가요. 기록은 이 폰에 그대로 있어요.

## 6단계. 입양 홍보카드 만들기 (홍보 탭)
임보 기록으로 입양 홍보 그림을 한 장 만들어요. 앱·웹 아래쪽의 **홍보** 탭에서 해요.

1. **홍보** 탭을 열고 아이를 골라요.
2. 카드 모양을 골라요. **코르크보드** 또는 **폴라로이드** 중 하나예요.
3. **오픈카톡 링크** 칸에 입양 문의용 오픈채팅 주소를 적어요. 비워 두면 문의 줄이 빠져요.
4. **카드에 넣을 기록** 에서 넣고 싶지 않은 항목은 눌러서 꺼요.
5. 폰에 남기려면 **갤러리에 저장** 을 눌러요. 폰 앱에서는 갤러리의 **"너의 꽃길" 앨범** 에 들어가요. (갤러리가 바로 안 보이면 갤러리 앱을 닫았다 다시 열어 보세요.)
6. 카카오톡·인스타그램 등으로 바로 보내려면 **공유하기** 를 눌러요. 공유창이 열려요. (컴퓨터 화면에서는 공유하기 버튼이 보이지 않아요.)

- 아이 사진·이름·성별·나이·성격·최근 체중·접종·등록 여부·중성화·최근 병원 기록이 자동으로 들어가요. 내용을 고치려면 해당 탭에서 바꾸면 카드도 같이 바뀌어요.
- 전화번호·동물등록번호·집 주소는 카드에 넣지 않아요. (동물등록은 "등록 완료"인지만 보여요.)
- 모양·링크·넣을 기록은 아이마다 따로 저장돼요. 로그인했다면 계정에도 같이 저장돼요.

### 앱(APK)에서 저장·공유가 되게 하려면
이 기능은 플러그인 3개(`@capacitor/filesystem`, `@capacitor/share`, `@capacitor-community/media`)가 더 필요해서 **앱을 새로 만들어야** 해요. (`media` 가 갤러리 저장을 해 줘요.)
1. 저장소에 `docs/index.html`, `package.json`, `README.md` 를 올려요. (**Add file → Upload files** 로 같은 이름 파일을 덮어써요.)
2. **Actions → Android APK → Run workflow** 로 앱을 새로 만들고, 새 APK를 설치해요. (2단계와 같아요.)
   - **새 APK는 옛 앱 위에 덮어 설치되지 않아요.** (7단계의 같은 도장을 쓴 뒤로 만든 앱끼리는 덮어 설치돼요.) 옛 앱을 지우고 새로 설치해야 해서 폰에 있던 기록이 사라져요. 지우기 전에 **설정 → 백업 · 복원 → 백업 내용 만들기** 로 기록을 꼭 복사해 두세요. (구글 로그인으로 계정에 저장해 뒀다면 새 앱에서 로그인만 하면 돼요.)
   - 설정의 앱 정보에 **앱 버전: 2026.10.29 (홍보 카드 · 갤러리 저장)** 가 보이면 새 앱이에요.
- 앱(APK)은 만들 당시의 화면을 그대로 담아요. 그래서 새 APK를 만들기 전에는 앱에 **홍보** 탭이 보이지 않아요.
- 웹 주소(GitHub Pages)는 올리고 1~2분 뒤부터 바로 새 화면이에요. 폰의 웹 화면에서는 **갤러리에 저장** 이 이미지를 다운로드 폴더에 저장하고(갤러리의 "다운로드" 앨범에 보여요), **공유하기** 가 공유창을 열어요. 컴퓨터에서는 **이미지 파일로 저장** 만 보이고 다운로드 폴더에 저장돼요.
- `package.json` 을 올리지 않고 앱을 새로 만들면, 저장·공유를 눌렀을 때 "앱을 새로 만들어야 …" 안내가 떠요.
- 앱에서 **갤러리에 저장** 을 눌렀는데 "갤러리에 저장하지 못했어요 (○○○)" 라고 나오면, 괄호 안 글자가 보이게 화면을 캡처해서 알려주세요. 그동안은 **공유하기** 를 누르고 공유창에서 이미지를 저장하거나 보낼 수 있어요.
- 갤러리 저장은 이 앱이 폰 안에 사진 파일을 만드는 것뿐이에요. 앱이 카드를 서버로 보내지는 않아요. (구글 포토 같은 백업 앱을 켜 두었다면 그 앱 설정에 따라 올라갈 수 있어요.)

## 7단계. 다른 사람에게 테스트 앱 보내기 (링크 하나로)
앱을 만들 때마다 다운로드 주소(GitHub **Releases**)에 앱 파일이 **같은 주소로 저절로** 올라가요.
받는 사람에게는 아래 **안내 페이지 주소 하나만** 보내면 돼요.

`https://내아이디.github.io/저장소이름/install.html`

- 받는 사람은 그 페이지의 **앱 내려받기** 를 눌러 설치해요. 설치할 때 나오는 허용 화면도 페이지에 순서대로 적혀 있어요.
- 컴퓨터로 열면 QR 코드가 보여요. 폰 카메라로 비추면 폰에서 열려요.
- 아이폰은 앱 파일을 설치할 수 없어서, 같은 페이지에서 웹 주소(홈 화면에 추가)를 안내해요. 웹에서는 알람이 울리지 않아요.
- 카카오톡·네이버 앱 안에서 열면 다운로드가 막힐 수 있어요. 페이지에 크롬으로 여는 방법이 적혀 있어요.

### 올릴 파일 (이번에 바뀐 것)
- `.github/workflows/android.yml` — 바뀜. 올리면 앱 만들기가 저절로 시작돼요.
- `docs/install.html` — 새 파일. 받는 사람이 보는 안내 페이지예요.
- `signing/debug.keystore` — 새 파일. 앱에 찍는 "도장"(서명 열쇠)이에요. **지우지 마세요.**
- `README.md`

한 번에 올리려면 압축을 푼 폴더 안의 `.github`, `docs`, `signing`, `README.md` 를 **모두 선택해서** `https://github.com/내아이디/저장소이름/upload/main` 화면에 끌어다 놓고 **Commit changes** 를 눌러요.
(`.github` 폴더가 안 올라가면, 저장소에서 `.github/workflows/android.yml` 을 열고 연필(✏️) 버튼으로 내용을 전부 새 내용으로 바꾼 뒤 **Commit changes** 를 눌러요.)

### 도장(서명 열쇠)이 하는 일
- 앱은 만들 때마다 도장을 받아요. 도장이 매번 달라지면 새 앱이 옛 앱 위에 설치되지 않아서, 받는 사람이 옛 앱을 지우고 다시 깔아야 했어요.
- 이제는 `signing/debug.keystore` 의 **같은 도장**을 매번 써서, 새 버전을 **덮어 설치**할 수 있어요. 쓰던 기록도 그대로 남아요.
- 만들 때마다 앱의 버전 번호도 하나씩 커져요.
- 만든 앱이 이 도장으로 찍혔는지 Actions 화면의 **Check signature** 단계에서 확인하고, 다르면 빨간 X 로 멈춰요.
- 이 열쇠는 **테스트용**이에요. 저장소가 공개라서 누구나 볼 수 있고, 이 열쇠로 만든 가짜 앱도 덮어 설치될 수 있어요. 믿는 사람에게만 주소를 알려 주세요. Play 스토어에 올릴 때는 새 열쇠를 만들어 **비공개로** 보관해야 해요.

### 새 버전 보내기
1. 바뀐 파일을 올려요. (앱 화면이 바뀌었다면 `docs/index.html` 등)
2. **Actions → Android APK → Run workflow** 로 앱을 새로 만들어요.
3. 초록 체크가 뜨면 끝이에요. 받는 사람은 같은 주소에서 다시 받아 설치하면 새 버전이에요.
4. 만든 파일은 저장소 오른쪽의 **Releases → 너의 꽃길 테스트 앱 (자동 업데이트)** 에도 있어요.

### 처음 한 번만
- 이 도장을 쓰기 전에 만든 앱은 도장이 달라서 덮어 설치되지 않아요. 폰에 있는 옛 앱을 지우고 새로 설치해요. **이번 한 번만** 그래요. 그 뒤부터는 덮어 설치돼요.
- 지우기 전에 설정 → **내 계정** 에 "모두 저장됐어요" 가 보이는지 확인하세요.

### 받는 사람이 구글 로그인을 하려면
- Google Cloud Console → **Google Auth platform → Audience → Test users** 에 받는 사람의 구글 메일을 넣어야 해요. (최대 100명) 안 넣으면 "액세스 차단됨" 이 나와요. 로그인 없이 **나중에 하기** 로는 쓸 수 있어요.
- 로그인한 사람의 아이 정보·사진·기록은 내 서버(Cloudflare)에 저장되고 내가 볼 수 있어요. 안내 페이지에도 이 내용이 적혀 있어요.

### 문제가 생기면
- Actions 에서 **Check signing key** 가 빨간 X → `signing/debug.keystore` 가 저장소에 없다는 뜻이에요. `signing` 폴더를 다시 올려요.
- **Check signature** 가 빨간 X → 앱이 도장으로 찍히지 않았어요. 화면을 캡처해서 알려주세요. 그동안 앱 파일은 예전 방법(Artifacts)으로 받을 수 있어요.
- **Publish download link** 가 빨간 X → 화면을 캡처해서 알려주세요. 앱 파일은 예전 방법(Artifacts)으로 받을 수 있어요.
- 안내 페이지의 **앱 내려받기** 를 눌렀는데 "Not Found" → 아직 앱 만들기가 끝나지 않았거나 한 번도 성공하지 못한 거예요. Actions 에서 초록 체크를 확인해요.
- 안내 페이지가 안 열려요 → `docs/install.html` 을 올린 뒤 1~2분 기다려요.

## 알아두세요
- 아이폰은 이 방법으로 알림이 울리지 않아요. 아이폰 앱을 만들려면 맥과 애플 개발자 계정이 필요해요.
- 숫자 공유 코드는 4단계(서버)를 만든 뒤에만 나와요. 서버가 없거나 연결되지 않으면 긴 글자 코드로 만들어져요.
- 구글 로그인은 4·5단계(서버와 구글 설정)를 마친 뒤에만 돼요. 끝내지 않았다면 "나중에 하기" 로 예전처럼 쓰면 돼요.
- 알림은 휴대폰 안에서 예약돼요. 폰을 껐다 켜도 앱을 한 번 열면 다시 예약돼요.
- 매월 29~31일로 정한 약은, 그 날짜가 없는 달에는 알림이 건너뛰어질 수 있어요.
- 이 폴더는 직접 빌드해 보지 않은 채로 만들었어요. 빌드가 실패하면 오류 화면을 알려주세요.
- 구글 로그인은 가짜 구글 서버로 처음부터 끝까지 시험했어요. 진짜 구글 화면과, 폰에서 구글 창이 앱으로 돌아오는 부분은 직접 해 봐야 확인돼요. 안 되면 화면을 캡처해서 알려주세요.
- 홍보 카드의 손글씨 글꼴(Jua·Gaegu·Single Day)은 인터넷에서 받아와요. 인터넷이 안 되면 기본 글꼴로 그려져요.
- 갤러리 저장(앱)은 가짜 폰 환경으로 호출 순서까지만 시험했어요. 진짜 폰의 갤러리에 보이는지는 직접 해 봐야 확인돼요. 안 되면 화면을 캡처해서 알려주세요.
- 다운로드 주소 자동 생성과 같은 도장 서명은 단계별로 가짜 환경에서 시험했어요. 진짜 GitHub 에서는 처음 돌려 보는 거라, 빨간 X 가 뜨면 화면을 캡처해서 알려주세요.
