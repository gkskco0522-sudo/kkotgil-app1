공유 코드 만들기

아이 정보를 다른 사람에게 보내는 코드예요. 받은 사람이 아래 '공유 코드로 아이 추가'에 붙여넣으면 돼요. 사진은 포함되지 않아요.

숫자 코드를 만들면 아이 정보가 서버에 24시간 동안 임시로 보관돼요. 받은 사람이 불러오면 바로 지워져요.

공유 코드로 아이 추가

받은 코드를 입력하거나 붙여넣으면 그 아이의 정보가 이 기기에 추가돼요. 같은 아이를 다시 불러오면 최신 내용으로 덮어써요.

숫자 코드는 만든 뒤 24시간 안에, 한 번만 쓸 수 있어요.

카드는 다운로드 폴더에 저장돼요.
