안드로이드 폰에 설치하기 갤럭시 등

앱 내려받기kkotgil.apk · 안드로이드 전용
  1. 내려받기위의 파란 버튼을 눌러요. “이 파일은 기기에 해로울 수 있어요” 같은 안내가 나오면 다운로드·확인·그래도 저장 중 보이는 걸 눌러요.
  2. 파일 열기다 받아지면 열기를 눌러요. 안 보이면 내 파일(또는 파일) 앱 → 다운로드에서 kkotgil.apk를 눌러요.
  3. 설치 허용“보안을 위해 이 출처의 앱 설치가 차단됐어요”가 나오면 설정을 누르고, 이 출처 허용 스위치를 켠 뒤 뒤로 돌아와요.
  4. 설치설치를 눌러요. Google Play 프로텍트 화면이 나오면 상세 정보 → 무시하고 설치(또는 그래도 설치)를 눌러요.
  5. 열기설치가 끝나면 열기를 눌러요. 알림을 보내도 되냐고 물으면 허용을 눌러요. 약·접종 알람이 울리려면 꼭 필요해요.

카카오톡·네이버 같은 앱 안에서 이 페이지를 열었다면 다운로드가 안 될 수 있어요. 화면 구석의 메뉴(⋮ 또는 …)에서 다른 브라우저로 열기를 눌러 크롬으로 열어 주세요.

새 버전이 나오면 같은 주소에서 다시 받아 설치하면 돼요. 쓰던 기록은 그대로 남아요.

설치 없이 바로 써 보기 아이폰 · 컴퓨터도 가능

웹 주소를 열고 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

  • 안드로이드 — 크롬으로 열고 ⋮ 메뉴 → 홈 화면에 추가

웹으로 쓰면 약·접종 알람은 울리지 않아요. 알람은 안드로이드 앱에서만 돼요.

로그인과 내 기록

첫 화면의 Google 계정으로 시작하기를 누르면 기록이 내 구글 계정에 저장돼요. 폰을 바꾸거나 앱을 다시 설치해도 로그인만 하면 돌아와요.

나중에 하기를 누르면 로그인 없이 이 폰에만 저장하며 쓸 수 있어요.

로그인하면 아이 정보·사진·기록이 이 앱을 만든 사람의 서버에 저장되고, 만든 사람이 볼 수 있어요. 원하지 않으면 로그인하지 않고 쓰세요.

지금은 테스트 중이라 미리 알려 준 구글 계정만 로그인돼요. “액세스 차단됨”이 나오면 만든 사람에게 구글 메일 주소를 알려 주세요.

막히면 이렇게

“앱이 설치되지 않았어요”라고 나와요

예전에 받은 ‘너의 꽃길’이 폰에 남아 있으면 겹쳐 설치가 안 될 수 있어요. 옛 앱 아이콘을 길게 눌러 삭제한 뒤 다시 설치해 주세요. 로그인해 둔 기록은 다시 로그인하면 돌아와요.

갤럭시에서 설치가 막혀요 (자동 차단)

삼성 갤럭시는 ‘자동 차단(Auto Blocker)’이 켜져 있으면 스토어 밖의 앱을 설치할 수 없어요. 폰 설정 → 보안 및 개인정보 보호 → 자동 차단을 잠시 끄고 설치해 보세요. 설치한 뒤에 다시 켜도 돼요. (메뉴 이름은 폰마다 조금 달라요.)

내려받기가 안 돼요

카카오톡 같은 앱 안에서 열었다면 크롬으로 열어 주세요. 그래도 안 되면 와이파이나 데이터 연결을 확인하고 다시 눌러 보세요.

알림이 안 와요

폰 설정 → 앱 → 너의 꽃길 → 알림이 켜져 있는지 확인해 주세요. ‘알람 및 리마인더’ 같은 항목이 있으면 허용해 주세요.

그 밖에 문제가 있어요

화면을 캡처해서 만든 사람에게 보내 주세요. 어떤 화면에서 막혔는지 보이면 빨리 고칠 수 있어요.

테스트 중인 앱이라 화면이나 기능이 바뀔 수 있어요.
